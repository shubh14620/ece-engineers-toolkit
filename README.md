## 📌 About the Project

**ECE – Engineer's Toolkit v10.0** is a fully browser-based mega-toolkit for AKTU Electronics & Communication Engineering Students & Engineers. Built as a **single HTML file** — no installation, no login, no ads. Just open and use.

> 💡 Works offline after first load · 100% Free · Zero dependencies · Single HTML file

## 🧪 ECE Simulators — 7 Real-Time

Section opens with a **menu grid of 7 simulator cards**. Click any card to open that specific simulator. A **← Back** button inside each simulator returns you to the simulator menu (not to Home). All simulator outputs and canvas drawings are cleared when you navigate away.

| Simulator | Description |
|---|---|
| **〰️ Waveform Visualizer** | Sine / Square / Triangle / Sawtooth — Vrms, Vpp, T |
| **📈 RC / RL Curve** | Charging & discharging with τ marker |
| **📉 Bode Plot** | LPF / HPF / BPF — Magnitude + Phase, fc marker |
| **⭕ Phasor Diagram** | VR, VL, VC, Z, I, φ, Power Factor |
| **🔗 Logic Gate Simulator** | 2-gate chain + circuit diagram + full truth table |
| **⏱️ 555 Timer** | Astable (square wave + Vc) & Monostable |
| **🔢 Boolean → Truth Table** | Auto-generate from any Boolean expression |
